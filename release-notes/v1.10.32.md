# GarageWildHeart v1.10.32

2026年11月4日公開。

会話を読み進めるときの保存処理を軽くし、立ち絵や背景を一通り見たあとのメモリ使用量を抑えました。診断結果の読み返しと、待機中の画面更新も整理しています。

音声の品質・長さ・ループ位置を保ったまま圧縮方法を見直し、配布サイズを削減しました。採用された新しいガレージ内外の背景も収録しています。

Windows 64bit向けです。ZIPをすべて展開し、`GarageWildHeart.exe` を開いてください。**.NETは同梱していません。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。** インストール後はオフラインで遊べます。`GameData` フォルダーも実行ファイルと同じ場所に置いてください。

保存形式は4のままです。v1.10.25以降のセーブで再開できます。会話・選択肢・採点・画像の解像度・音声の内容は今回変更していません。
