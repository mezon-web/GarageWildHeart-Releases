# GarageWildHeart v1.10.36

全3話の診断と会話を見直し、調べた結果から修理を選ぶところまで進めやすくしました。

- 会話送り、選択肢、検査、修理案の根拠選びをキーボードで操作できます。
- 診断の比較画面では変化した数値と次の操作を強調。レポートには自分で選んだ修理と追加で調べた観察が残ります。
- 採点では、原因を絞った観察と、修理案に添えた根拠をそれぞれ評価します。
- 検査を省いた場合や別の修理を提案した場合に、実際の観察に合ったセリフが出るよう調整しました。祭りの朝の連絡も短くし、夕方の再会につなげました。
- 現行形式の途中オートセーブがある場合、「はじめから」で上書きを確認します。
- 同梱の操作説明と攻略チャートは、現在の部品名、ボタン名、波形の自動記録に合わせて更新しました。

Windows x64向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。ZIPをすべて展開し、`GameData` フォルダーの隣にある `GarageWildHeart.exe` を起動してください。

保存形式は5です。旧版から更新した場合は「はじめから」で開始してください。旧形式のオートセーブは新規開始時に、手動枠は保存先に選んだ時点で置き換わります。
