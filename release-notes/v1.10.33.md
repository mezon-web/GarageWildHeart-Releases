# GarageWildHeart v1.10.33

2026年11月5日。

修理の相談画面を整理しました。候補の上に並んでいた検査結果の文章を外し、右上の「ノートを見る」から、必要なときに証拠を読み返せます。「修理候補へ戻る」で、会話や判断を進めず、同じ候補の画面へ戻れます。全3話に反映しています。

診断ノートでは、見立ての振り返りを問いの横に小さく配置。依頼の詳細は右端へ揃え、会話へ戻るボタンとの間隔を広げました。

第1話のコイル候補は「入庫時に2番に付いていたコイル」と表示し、現在の装着位置を2番／4番で区別します。部品の役割説明・修理費用・修理対象・採点は維持しています。タイトル画像は、アオイが小さな木箱に浅く座る、採用されたイラストへ更新しました。

Windows 64bit向けです。ZIPをすべて展開し、`GarageWildHeart.exe` を開いてください。**.NETは同梱していません。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。** インストール後はオフラインで遊べます。`GameData` フォルダーも実行ファイルと同じ場所に置いてください。

保存形式は4のままです。シナリオと音楽は変更していません。
