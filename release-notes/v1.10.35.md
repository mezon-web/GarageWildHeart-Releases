# GarageWildHeart v1.10.35

三台の診断を終えたあと、片付け、港の祭り、帰り道へとつながる終章を追加しました。一週間後の休日には、親しくなった相手との新しい後日談CGが登場します。

- 六人が集まる祭りのCGと、アオイ・レイ・ナツ・リンの四枚の休日CGを追加。
- 見た絵をCGアルバムへ記録し、タイトルやメニューから読み返せます。
- お客さんごとの確認結果に合わせて翌朝の報告を調整。代替送迎と本人の車の運行再開を区別しました。
- 終了後の操作と保存再開を整理。保存失敗時は終了画面に残って再試行できます。

Windows x64向け。.NET 10 Desktop Runtime x64が必要です。ZIPをすべて解凍してGarageWildHeart.exeを開いてください。GameDataフォルダも同じ場所に置きます。

今回は「はじめから」で開始してください。旧版の途中セーブの互換性は対象外です。
