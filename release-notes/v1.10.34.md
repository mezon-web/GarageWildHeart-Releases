# GarageWildHeart v1.10.34

2026年11月5日。

調べたことから自分で見立てを考えやすいよう、会話と診断画面を整えました。

- 見立ての振り返りは、自分が選んだ回答と取得した観察に合う内容へ。選んでいない仮説を指摘しません。
- 第1話は、ノートを読み終えたら修理候補へ進み、同じ相談を繰り返さない流れにしました。
- 第2話は、数値の読み方を先に、原因の解釈を回答後に説明します。測定前の予想と、あとから見立てを更新する流れも残しています。
- 第3話の修理後方針は、始動と吸引停止を提案するか、レイと項目を整理するかの2択にしました。
- 診断画面の重複した説明と補助枠、戻る操作名を整理しました。修理案と診断レポートには、各証拠が何を調べた観察かを添えています。

修理対象・費用・採点、画像・音楽は維持しています。会話構成を改訂したため、今回は「はじめから」で開始してください。以前の途中セーブの互換性は対応対象外です。既存の保存ファイルは変換・削除しません。保存形式は4です。

Windows 64bit向け。ZIPをすべて展開し、`GarageWildHeart.exe` を開いてください。**.NETは同梱していません。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。** `GameData` も実行ファイルと同じ場所に置いてください。インストール後はオフラインで遊べます。
